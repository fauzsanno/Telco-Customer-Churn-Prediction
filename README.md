# Telco Customer Churn Prediction

A Machine Learning project designed to predict customer churn in the telecommunications industry. The project uses an ensemble learning model to estimate churn probabilities and categorize customers into risk segments, helping businesses identify customers who may be likely to leave their services.

### Key Features
- Customer churn probability prediction
- Customer risk segmentation
- Ensemble Machine Learning model using Logistic Regression, CatBoost, and LightGBM
- Interactive web application built with Streamlit
- Automated testing for prediction functionality

### Tech Stack
Python, Pandas, NumPy, Scikit-learn, CatBoost, LightGBM, Joblib, Streamlit, and Pytest.

### Objective
To support data-driven customer retention strategies by identifying customers at risk of churn and providing actionable predictive insights for business decision-making.
